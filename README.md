## 🇬🇧 English

### 📌 Overview

This repository documents my hands-on learning journey in **Applied Machine Learning (AML)**. Day 1 focuses on transforming a real-world problem into a machine learning task, preparing the data, training models, and evaluating their performance.

### 📂 Day 1 — Project Overview

- **Dataset:** California Housing Dataset from Scikit-learn.
- **Task:** Regression — predicting median house values.
- **Environment:** Google Colab.

### 📚 Key Concepts Covered

1. **Problem Framing — The Five-Question Framework:** Identifying the business problem, target variable, input features, evaluation metrics, and baseline model.
2. **Traditional Programming vs. Machine Learning:** Understanding how machine learning models learn patterns from data instead of relying entirely on manually defined rules.
3. **Train/Test Split:** Separating training and testing data to evaluate model performance on unseen examples and reduce the risk of data leakage.
4. **Baseline Model:** Building a simple reference model using `DummyRegressor` to establish a performance benchmark.
5. **Linear Regression:** Training a regression model with `scikit-learn` to learn relationships between input features and the target variable.
6. **Model Evaluation:** Measuring performance using Mean Absolute Error (`MAE`), Root Mean Squared Error (`RMSE`), and the coefficient of determination (`R²`).

### 🛠️ Tech Stack

- **Python**
- **Scikit-learn**
- **Pandas**
- **NumPy**
- **Google Colab**

### 🎯 Learning Objectives

By the end of Day 1, I practiced how to:

- Frame a problem as a supervised learning task.
- Separate features (`X`) from the target (`y`).
- Split data into training and testing sets.
- Establish a baseline and train a Linear Regression model.
- Evaluate model performance using multiple metrics.

## 🇸🇦 العربية

### 📌 نظرة عامة

يوثّق هذا المستودع رحلتي في التعلم العملي لمجال **تعلم الآلة التطبيقي (Applied Machine Learning)**. يركز اليوم الأول على تحويل مشكلة واقعية إلى مسألة تعلم آلة، وتجهيز البيانات، وتدريب النماذج، ثم تقييم أدائها باستخدام مقاييس مناسبة.

### 📂 نظرة عامة على مشروع اليوم الأول

- **مجموعة البيانات:** مجموعة بيانات منازل كاليفورنيا (`California Housing Dataset`) من مكتبة Scikit-learn.
- **نوع المهمة:** الانحدار (`Regression`) للتنبؤ بالقيم الوسيطة للمنازل.
- **بيئة العمل:** Google Colab.

### 📚 المفاهيم التي تعلمتها

1. **تحديد المشكلة — إطار الأسئلة الخمسة:** تحديد مشكلة العمل، والمتغير المستهدف، والميزات المدخلة، ومقاييس التقييم، والنموذج المرجعي.
2. **البرمجة التقليدية مقابل تعلم الآلة:** فهم الفرق بين كتابة القواعد يدويًا وتعلم الأنماط والعلاقات من البيانات.
3. **تقسيم البيانات (`Train/Test Split`):** تقسيم البيانات إلى مجموعتي تدريب واختبار لتقييم أداء النموذج على أمثلة لم يتدرب عليها، وتقليل خطر تسرب البيانات.
4. **النموذج المرجعي (`Baseline Model`):** استخدام `DummyRegressor` لبناء نموذج بسيط يمثل نقطة مرجعية نقارن بها النماذج الأخرى.
5. **الانحدار الخطي (`Linear Regression`):** تدريب نموذج باستخدام `scikit-learn` لتعلم العلاقات بين الميزات المدخلة والمتغير المستهدف.
6. **تقييم النماذج:** قياس الأداء باستخدام متوسط الخطأ المطلق (`MAE`)، وجذر متوسط مربع الخطأ (`RMSE`)، ومعامل التحديد (`R²`).

- **NumPy:** العمليات العددية والحسابية.
- **Google Colab:** بيئة تنفيذ الأكواد والتجارب.

- تقسيم البيانات إلى مجموعتي تدريب واختبار.
